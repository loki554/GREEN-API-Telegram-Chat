# GREEN-API Telegram Chat

Простецкйи веб-интерфейс для отправки и получения текстовых сообщений в Telegram через [GREEN-API](https://green-api.com/telegram). Сделан как тестовое задание на должность фронтенд-разработчика React. В качестве вспомогательного инструмента использовался Claude AI

## Возможности

- Вход по учётным данным инстанса GREEN-API (`idInstance`, `apiTokenInstance`). `apiUrl` подставляется автоматически.
- Создание чата по номеру телефона получателя.
- Отправка текстовых сообщений методом [SendMessage](https://green-api.com/telegram/docs/api/sending/SendMessage/)
- Получение входящих сообщений по технологии [HTTP API](https://green-api.com/telegram/docs/api/receiving/technology-http-api/): `receiveNotification` → обработка → `deleteNotification`
- Статусы отправленных сообщений (✓ / ✓✓; прочитанные отмечаются синим цветом) и аватары собеседников.
- Переписка и данные для входа сохраняются в `localStorage` браузера

## Требования

- [Node.js](https://nodejs.org/) 22.12 или новее (npm входит в комплект)
- Инстанс GREEN-API для Telegram в статусе `authorized`: аккаунт Telegram привязан в [личном кабинете](https://console.green-api.com)

## Установка и запуск

```bash
git clone <url-репозитория>
cd <папка-проекта>
npm install
npm run dev
```

Откройте http://localhost:5173 и войдите с `idInstance` и `apiTokenInstance` из личного кабинета GREEN-API

## Настройка инстанса

Чтобы в чате появлялись ответы, у инстанса должны быть включены входящие уведомления, а `webhookUrl` должен быть пустым: уведомления тогда попадают в очередь HTTP API. Если это не так, после входа сверху появится плашка с кнопкой «Включить», которая сама выставит нужные настройки. То же можно сделать вручную в личном кабинете

Для проверки нужны два разных аккаунта Telegram: инстанс привязан к одному, а чат создаётся с номером другого

## Сборка для продакшена

```bash
npm run build     # статические файлы в папке dist/
npm run preview   # локальный просмотр собранной версии
```

Содержимое `dist/` можно выложить на любой статический хостинг (GitHub Pages, Netlify, nginx). Пути в сборке относительные, поэтому проект работает и из подпапки. Сервер не нужен: браузер обращается к GREEN-API напрямую

## Тесты


## Стек

React 19, TypeScript, Vite, Vitest, Testing Library. Сторонних UI-библиотек и менеджеров состояния нет

## Структура

```
src/
  api/         клиент GREEN-API и типы ответов
  lib/         разбор уведомлений, работа с номерами, localStorage
  state/       редьюсер чатов
  hooks/       опрос очереди уведомлений, аватары, состояние чатов
  components/  экраны входа и чата
```
